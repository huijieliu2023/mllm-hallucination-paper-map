# MLLM Hallucination Paper Map

An independently maintained literature map for hallucination, detection and evaluation, mitigation, reasoning, and faithfulness in multimodal large language models.

Published with GitHub Pages: <https://huijieliu2023.github.io/mllm-hallucination-paper-map/>

The deployable static site lives in `docs/`. Its source data and update scripts remain in `dist/`, `data/`, and `scripts/`.
